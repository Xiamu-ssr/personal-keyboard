# 账户、权益与部署

国内先用手机号验证码；普通离线输入不登录。Google 登录和支付渠道后续再接，本轮不要求 Play 开发者账号。

## 权益

`cloud/config/plans.json` 提供初始套餐，后台管理已发布版本与调整记录。

| 能力 | 免费新账号 | 付费 |
| --- | --- | --- |
| 转写 | 一次性10,000个字符 | 待定价 |
| 军师 | 一次性20次 | 待定价 |
| 本机历史与记忆缓存 | 支持 | 支持 |
| 个人记忆同步 | 基础能力 | 支持 |
| 完整历史 / 截图备份 | 不提供 | 可按套餐开启 |

转写按成功最终文本 NFC 规范化后的非空白 Unicode 码点计量；中间字和个人改写不重复扣。一次成功三条回复扣一次，“更多”新建任务，成功再扣一次。失败 / 取消释放，同任务重试不重复扣。预留与结算均为 PostgreSQL 事务。

套餐发布后不可原地修改；发放保存快照，改版不重送欢迎礼包。运营调整需填写原因并审计。付费价格、商户支付及到期存储策略尚未开放，App不展示假付款成功。

## 后台

Cloud 自带概览、用户与权益、套餐、任务和审计页面。显示脱敏手机号、用量、模型、错误码与提示词哈希；不提供默认查看私人聊天的入口。管理员独立登录，写操作校验 CSRF 和来源，密码与会话均不进入公开仓库。提示词随代码发布，可通过部署版本回退。

## 服务与数据

ECS 上独立 API / PostgreSQL 容器，通过 `https://106.14.73.99/keyboard-api` 提供服务；后台位于 `/admin/`。App暂时内置这个IP，仍正常校验证书；后续有域名可更换稳定入口。

目标：文字历史与截图留手机，Cloud 持久保存个人记忆主本；账户基础同步把热词、文风、人物缓存到手机。学习任务临时上传必要片段，完整历史 / 截图备份另按付费权益开放。推理处理、记忆持久存储和历史备份分别说明保留策略，不宣称端到端加密或供应商零留存。

当前 0.4 仍为最长 24 小时模型文字任务缓存、设备加密付费同步包与本机记忆主本；新主本和基础同步尚未迁移，本轮不改变运行时套餐配置。

## 短信状态

当前个人阿里云账号已开通短信服务，尚无企业资质、可用签名和模板，没有购买套餐或发送短信。用户已报告另一个企业账号完成登录，资质、签名和模板仍待实际核验。阿里云国内短信要求企业资质或企业授权完成签名报备；账号实名认证、短信报备和 APP备案是不同事项，换手机号登录不能替代备案。
