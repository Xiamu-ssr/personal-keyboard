# 账号、权益与部署

## 登录不是上架渠道

国内默认手机号验证码登录；海外使用 Google 登录。两者对应稳定的产品 userId，安全绑定后共用权益。重装、换机或绑定另一个登录方式不重发礼包；未验证归属不能自动合并账号。普通离线键盘不强制登录。

短信验证码需要短有效期、单次消费、重发冷却、尝试上限和按号码 / IP / 设备的限流；正式通道在 Cloud 接入，不从 APK 调短信平台。手机号和验证码不进入普通日志。

2026-10-21 核验：阿里云普通国内短信签名需要企业资质与实名报备；个人自用资质不能完成该报备。若暂无企业资质，可评估官方号码认证的“短信认证”产品，不能假定普通短信通道直接获批。普通验证码短信按量小档为 ¥0.045/条，即 1,000 条约 ¥45；短信认证是不同产品，价格与资格另核。不在此处提交注册、资质或购买。

## 免费与付费策略

唯一配置来源为 `cloud/config/plans.json`。

| 权益 | 免费新账号 | 付费套餐 |
| --- | --- | --- |
| 转写字符 | 一次性 10,000 | 后台配置，尚未定价 |
| 军师生成 | 一次性 20 次 | 后台配置，尚未定价 |
| 本地历史 / 记忆 | 支持 | 支持 |
| 产品云同步 | 不提供 | 可按套餐开启 |

转写按成功 ASR 最终文本经 NFC 规范化后的非空白 Unicode 码点计数；中文、字母、数字、标点均按此规则，空白不计。实时中间结果可能修订，不能逐包累加。个人口吻改写不再次扣字符，记忆提取不另设用户计费项，其成本受后台预算控制。

一次军师成功生成一组结果（3 种风格各一条）计 1 次。“更多”新建任务，成功再计 1 次；读缓存返回、失败、取消和同一任务重试不重复计费。语音已成功转写、后续个人改写失败时，保留原文，转写计量仍成立。

调用前预留上限，音频时长和返回文字不能无限延长；达到额度上限及时停止供应商，不能先放出无限中间字再只计一小段。任务失败释放未完成预留；已结算的成功任务重试恢复原结果。预留、结算、支付与赠送均需数据库锁 / 唯一键，内存 Map 参考实现不代替生产事务。

改价、改额度是新策略版本。欢迎礼包按账号唯一发放，老用户已领到的版本保留，不因后台改数字清空或重新赠送。付费先生成服务器定价订单；供应商签名、金额、币种、商品、交易与账号归属验证后才授予权益，重复回调不重发。

## 产品云同步

免费账户的历史和个人记忆只存本机，不显示存储平台、WebDAV、Bucket 或授权码。付费开启“云同步”后，App 加密增量包，Cloud 管理私有对象存储和每个用户的清单、版本与删除记录。用户只见同步状态、设备恢复和数据管理。

换机登录后还需安全恢复解密能力，不能宣称登录本身可以凭空解密。具体恢复凭据方案留在同步实现阶段；后台不能默认查看密钥或私人原文。上传开关、数据范围和删除行为对用户可见。

到期或降级不清空本地资料；停止新增云同步，保留期内提供下载 / 导出。云端保存期限、容量与导出窗口均为待定策略，不在代码中偷偷设成永久或立刻删除。

## 运营后台

| 页面 | 能看到或操作什么 |
| --- | --- |
| 用户与权益 | 脱敏账号、状态、套餐版本、赠送 / 购买 / 调整账本、可用与预留量 |
| 套餐与订单 | 草稿、发布版本、价格 / 额度 / 云同步能力；验签与退款记录 |
| 用量与成本 | 用户字符 / 次数，与供应商秒数 / token / 金额分开；按账号、模型、日期汇总 |
| 模型与故障 | 路由、成功率、限额、断线 / 超时、失败成本；不记录供应商明文密钥 |
| 提示词与任务 | 改写 / 军师 / 学习的版本、发布和回滚；任务来源范围与校验错误 |
| 审计 | 管理员、时间、修改原因与前后版本；不把聊天原文当常规管理报表 |

后台属于 `cloud/`，使用独立管理员认证和最小权限；Spec 中这是目标页面结构，当前尚未实现管理站点。

## 容器与稳定域名

`cloud/deploy/compose.yaml` 现阶段只启动契约骨架，loopback 8088，不是公网商业服务。目标由 HTTPS 反代转入容器，数据库独立持久化，任务 worker 可从同一镜像另起进程。App 配置服务域名，不写供应商入口或 ECS 管理地址；服务器迁移通常只更改域名解析。

## 上线要求与渠道

备案取决于提供的互联网信息服务，不取决于微信、手机号或 Google 登录。国内联网 App 应按实际主体、域名 / IP 与服务形态办理 APP 备案；域名 / 网站、商业经营许可与平台审核不能混成一个动作，也不能把 APP 备案视为全部收费资格。正式收费前按主体与业务核实要求。

Google 登录使用 Google Cloud OAuth / Credential Manager，不以购买 Play 开发者账号为前提。Play 分发账号当前为 US$25 一次性注册费；新个人账号有连续 14 天、至少 12 名测试者的封闭测试要求，达到条件后再申请生产权限。通过 Play 销售数字权益 / 订阅通常接 Play Billing；地区例外需满足相应项目，不能把“一次性 25 美元”当成全部发行成本。

微信登录是另一个可选身份适配器，本轮不作为手机号 / Google 路线的前置，不提交微信认证或代填主体。正式上线还需落实输入法数据使用说明、用户数据删除与截屏能力的商店审核；不因此默认扩大读屏或采集范围。

当前未注册新的登录平台、购买短信、充值、备案或开通支付。本轮完成的是目标结构与代码骨架，生产域名、主体和供应商配置待落实。
