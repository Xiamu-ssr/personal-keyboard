# 真实 Android 画面

豆豆输入法是原生 APK，包名 `app.doudou.ime`。Node / ws-scrcpy 负责传输实际设备的视频与触摸，不把 HTML 包装成安卓画面；静态网页中的手机截图明确标注为截图。

```sh
npm ci
npm run android:build
npm run demo:setup
npm run spec:serve
```

打开 `http://127.0.0.1:8560`，点“真实 APK”，选择已经解锁并授权 ADB 的设备。只针对选定设备安装、投屏；不自动开启模拟器。手机厂商的安装扫描、确认或本人验证仍须正常完成。

只有选择临时授权，工具才临时启用豆豆输入法与主动截屏；停止时恢复原输入法、已启用列表和辅助功能设置。正常自用可从 App 首页手动选择键盘、按需授权麦克风和主动截屏。

当前真实能力是离线拼音、SQLite 资料、系统语音适配与本地中文 OCR。没有内置模型账号；没有服务或额度时，显示实际错误，不返回预写的“智能结果”。模型整理、生成、更多与取消已经留好适配入口，后续接真实账号联调。

本轮 OPPO 验收及尚未接通项集中在 [验收记录](acceptance.md)。普通键盘的可用性不能从网页截图推定，单台 OPPO 的结果也不代表所有聊天 App / ROM。

投屏宿主只监听本机：Spec 8560、画面 8561。固定 ws-scrcpy commit `cd6cea6ebde17af6685c2b325183fc24bef9d52b`，禁用网页 shell、文件浏览、DevTools 和 iOS。不会部署为公网远程设备控制服务。已有投屏进程时先停止原工具，本次仅清理自己创建的进程与转发。
