# 验收 · 0.4.0-alpha.1 · 2026-10-21

本版把 Android、产品 Cloud 和域图规格连成同一产品；短信资质、供应商凭据与商户支付仍待配置。没有向真人发送短信，没有发生新的付费模型调用。

## 已验证

- 25 项 JVM 测试通过：真实 JNI 拼音、输入状态、差异反馈、人物隔离与同步向量时钟。
- 18 项 Android 15 / API 35 instrumentation 测试通过：原生打字、工具与语音、缩矮截屏 / 本地 OCR / 草稿保护、资料管理；SQLite v1 升级、跨设备 UUID 映射、并发修订与删除恢复、长历史分片及重复学习防护。
- APK 与测试 APK 构建通过，Android lint 无错误；同一签名可覆盖上版安装。Android 实际通过公开 IP 的正常 TLS 校验，未跳过证书验证。
- 5 项 Cloud 测试通过，集成项使用隔离的真实 PostgreSQL：短信单次验证、跨设备欢迎额度只发一次、并发结算、同任务重试、失败 / 取消释放、异步模型任务、ASR WebSocket、刷新令牌重放、付费同步 CAS、后台 CSRF 与不可变套餐。供应商在测试中使用明确的替身，没有冒充真实服务成功。
- 仓库检查通过：域内子节点、每对域最多来回两条线、提示词目的地、滚动历史与自动跟随。后台与 SPEC 已在浏览器核验；手机宽度 390px 无页面横溢。

## 部署与发布

独立 API 和 PostgreSQL 容器已部署到 ECS，经 HTTPS /keyboard-api 提供服务；数据库与存储持久化，API 仅监听服务器 loopback。后台为独立认证，显示真实零用户与服务待配置状态。支付入口保持关闭，付费套餐保留草稿。

公开下载为本轮测试的同一 APK：2fdd58cf38c097ddac7be412edad0f148fc7640b01c6c7654b5943179c3c631b。9 张原生截图和两段实际操作录屏只包含练习区与测试资料；录屏剪去等待和系统桌面，没有虚构云端文字。公开在线 Android 方案已删除，不再连接个人 Mac。

本轮使用独立虚拟机，未操作 OPPO。测试后关闭虚拟机、停止 Gradle，删除专用临时数据库容器，并核对虚拟机进程与 5580 / 5581 端口释放。Cloud 生产容器继续运行。

## 仍待验收

- 企业短信签名 / 模板与服务凭据；真实手机号登录和真实 ASR / LLM 的准确率、延迟、费用及质量。
- 本版 OPPO、微信 / QQ / Messenger 与其他 ROM 的实际兼容性。
- 定价、商户支付与可信支付回执；付费到期后的同步保留政策。当前不可购买。
- 海外登录、自动翻页、完整多语言预测、双拼 / 滑行 / 手写。基础中英文与本地 OCR 不等于这些能力已完成。

JNI 本轮未变；0.2 的 2,014 组 ASan / UBSan 边界输入仅作历史证据，没有重复运行。详细摘要见 verification.json。
