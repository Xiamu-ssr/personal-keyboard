# 已选方案与待定项

以下为本轮对齐的目标；[调研依据](research.md)与[已发布实现](implementation.md)分开。没有重新发布 APK 或迁移线上 Cloud。

## 已选择

- 历史与军师截图留手机；Cloud 管理热词、文风、人物主本，手机同步缓存。
- 自动学习直接启用，不提供询问 / 自动 / 关闭三档；明确纠词自动且可撤销，文风变化和人物冲突先确认。
- 军师一次多模态，携带截图、相关人物关系、文风及同对话近期表达，不附独立热词表。
- 一次输入一条历史，保留来源、实际填入稿与最后有效修改稿，不存逐次编辑时间线；学习不依赖发送回执。
- App 提交历史变化，Cloud 运行受限 LLM 任务、校验和落库；App 拉取记录变更缓存。不使用每用户目录挂载的通用 harness。
- 个人记忆同步为基础能力；完整历史 / 截图备份另按付费权益开放。

## 记录与更新

文风按场景关联小档案，先保留通用文风，再据证据分化，避免预先堆出几十种分类。人物 ID 标识“谁”，人物事实各有 ID，改公司只更新任职事实。LLM 提操作，Cloud 校验，手机同步 **整库增量、单条完整**。详见[历史与记忆](memory-and-sync.md)。

热词可用于 ASR，并在接入个人词库后改善本地候选排序；文风、人物主要用于语音整理与军师。离线缓存并不表示手机离线调用云端模型。

## 仍未定

视觉模型、学习预算和具体合批参数、图片保留期限及付费备份容量仍未定。没有固定五小时全库扫描，也不先指定证据条数。当前提示词与套餐实现不会只改几行配置来冒充完成协议迁移。
