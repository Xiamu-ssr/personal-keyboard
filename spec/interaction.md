# 键盘交互

键盘、语音、军师与设置是同一 App 的界面。修改反馈是学习机制，不是常驻模式。

## 面积与入口

一条候选 / 动作行，麦克风和军师各一个小入口，工具按需展开。设置管理热词、文风、人物、账户与备份；普通用户不填写供应商模型或密钥。

参考 Typeless 深灰层级、录音主按钮与动效，以及豆包清楚的键帽、间距和工具格。触摸范围和候选质量由 APK 验证。

## 语音

键区显示录音与实时文字，音量条只随真实音频变化。停止后保留最终转写；“按我的口吻整理”决定是否追加文字模型。失败不伪造结果，不丢已有草稿。

## 军师

点击后保留草稿，键盘缩矮；宿主布局稳定后截当前屏。结果就绪再展开，三种表达各一条，选择后填入，发送由本人决定。

更多只生成该风格的新候选；返回复用本次结果。补前文由本人滚动后补当前屏，首期不自动翻页。未知人物不强行归档。取消或切换输入框使旧任务失效，迟到结果不覆盖新草稿。

## 历史与资料

一次输入一条历史，保留来源、实际填入稿和最后有效修改稿，不展示逐次编辑时间线。军师历史同时留截图、识别出的聊天内容和所选回复。近期上下文优先本人修订后的表达，聊天事实以有说话人归属的画面内容为依据。

自动学习直接启用，不做三档选择；词条可看来源、修改和撤销，文风变化与人物冲突先确认。页面上的个人资料是 Cloud 主本的本机缓存；修改经 Cloud 校验后同步，离线修改排队提交。

个人记忆同步是基础能力，完整历史 / 截图备份单独按付费权益开放。供模型临时分析与云备份的用途分别说明。当前 APK 尚未迁移上述资料归属，见[当前实现](implementation.md)。
