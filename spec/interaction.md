# 键盘交互

键盘、语音、军师与设置是同一个 App 的不同界面；反馈学习不是一个常驻模式。军师推理与记忆更新的取舍见[推荐方案](design-options.md)。

## 面积与入口

上方只有一条候选 / 动作行，不做固定的“输入 / 语音 / 军师”三段式导航。麦克风和军师各一个小入口；工具按需展开。设置管理热词、文风、人物、账户与备份，普通用户不填写供应商模型或密钥。

视觉参考用户提供的 Typeless 深灰层级、录音主按钮与动效，以及豆包的清楚键帽、间距和工具格。实际触摸范围与中文候选质量用 APK 验证，不能靠网页尺寸推断。

## 语音

键区接管录音与实时文字，音量条只随真实音频变化。停止后保留最终转写；“按我的口吻整理”开关决定是否追加文字模型，ASR 的句末规整不等于个人文风。失败不伪造文字，也不丢已有草稿。

## 军师

点击后保留草稿，键盘缩矮；宿主布局稳定后截当前屏。结果就绪再恢复高度，显示三种表达各一条，选择后填入，发送由本人完成。原截图进入本机历史；已选直接多模态，尚未迁移运行时代码。

更多只生成该风格的新候选；返回使用本次已有结果，不重复请求。补前文由本人滚动后补当前屏，首期不自动翻页。人物未知就标未知，不强行归档。

取消或切换输入框使旧任务失效；迟到的结果不覆盖新草稿。军师和语音均按既定成功口径结算，失败不重复扣。

## 历史与记忆

本机历史保留最终转写和军师截图。建议关联实际填入版本及最后观察改稿，无法观察的最终文字不补猜。热词、文风和人物可以查看、修改与撤销，明确纠词自动且可撤销，文风变化和人物冲突先确认；具体整理触发条件待定，没有“五小时定时”的已定要求。

免费仅本地保存，付费可开产品云备份。备份与模型分析用途分开；暂不向用户暴露存储平台。当前 APK 的行为与供应商联调状态见[当前实现](implementation.md)。
