# 交互与业务状态

本页为目标行为：军师一次图文推理，无 OCR 前置；已发布 0.4 的差异见 [当前实现](implementation.md)。

## 面积与入口

不使用常驻“输入 / 语音 / 军师”三段式导航。正常键盘上方只有一条候选/动作行，麦克风和军师各占一个小入口；触摸命中区保留，图标本身不必很大。设置按需打开同一输入法 App 的管理页，包含人物图、个人词库、语音偏好、账户权益与同步。商业版不让普通用户填写供应商模型或密钥。

普通键区使用成熟中文键盘的列宽、错列、空格与退格位置。参考 Typeless、Typeoff 的单任务聚焦和录音反馈，不假设语音键盘已经解决完整中文拼音选词。最终底座需要实际输入评测。

## 军师高度随阶段变化

    普通键盘
       ↓ 点军师，保留已有草稿与选区
    低矮捕获条：取消 / 正在读取
       ↓ 宿主窗口布局与键盘 inset 确认稳定
    截取聊天区域，排除键盘与状态栏
       ↓ 截图、意图与相关记忆，一次图文请求
    展开到正常键盘高度附近：三种风格与回复
       ↓ 选一条
    填入原输入框，可继续改字；发送由用户操作

缩矮用于多看到聊天，结果就绪后展开用于阅读和挑选。不能为保持低矮把三条回复挤到不可读。捕获/识别阶段不永久占用结果高度。

## 状态表

| 状态              | 可观察行为                         | 出口                     |
| ----------------- | ---------------------------------- | ------------------------ |
| typing            | 正常候选与键区                     | 录音、军师               |
| recording         | 键区成为录音/文字区域              | 停止、取消               |
| capture-resizing  | 低矮，等宿主完成布局               | 布局稳定、取消           |
| capturing         | 截当前聊天，明确可停止             | 图文请求、失败           |
| understanding     | 同一次推理理解画面与人物           | 结果、未知身份、失败     |
| generating        | 显示进度，允许取消                 | 结果、失败               |
| suggestions       | 恢复高度，三个风格各一条           | 填入、更多、补前文、返回 |
| refining          | 保留当前候选，生成某个风格的新表达 | 新候选、返回旧候选       |
| recoverable-error | 保留草稿和已读上下文，显示原因     | 重试、返回键盘           |

取消会让当前 requestId 失效；迟到的结果不能再覆盖新草稿。切换聊天对象或输入框后，旧任务的结果不可自动填到新会话。

## 补读前文

补前文由本人滚动后点击“补当前屏”，再次缩矮截取。先保留当前建议，截图带帧编号，与已抽取的必要文字上下文共同进入新一次图文请求；按消息内容、人物和来源去重。首期不自动向上翻页。

群聊保留多位说话人；身份不清标未知，不自动写入个人事实。表情包、引用与图片保留画面语义的不确定性；不引入 OCR 降级分支。

## 三条回复、更多与返回

初次一次模型调用返回三种风格各一条，不是三种风格各三条。每条可直接填入；“更多”沿用当前上下文、意图及风格，只生成这个风格的候选。旧结果留在本次会话缓存，返回不再请求模型。

用户主动修改的输入草稿优先；任何读屏、风格切换、返回或失败都不能清空它。用户继续输入时，模型结果仍可查看，但不强行替换正在编辑的内容。

## 语音与记忆设置

语音识别与“按我的口吻整理”分开设置。关闭个人整理时，ASR 句末结果即可上屏；开启时，再用适用热词、文风和必要上下文请求文字模型。ASR 自带的去口头禅 / 基础规整另设选项，不等同个人文风学习。

历史与记忆同在本机，可设保留期限。记忆整理默认每约 5 小时检查新增内容，受系统后台调度影响，不保证整点运行；也可手动整理。失败保留未处理位置，不重复强化已处理证据。免费账户只本地保存；付费账户可开启产品云同步，不显示存储平台配置。模型分析与备份分别说明用途。新证据关联和自动补丁待迁移，当前实现与供应商联调状态单列。

云能力需登录；本地打字不强迫登录。用量在任务发起前校验并预留，失败释放，原任务重试恢复已有结果而不重复扣费。“更多”是新生成，成功后扣一次；返回本地旧结果不扣。语音按成功的 ASR 最终文本计字符，不重复累计中间结果和个人改写。
