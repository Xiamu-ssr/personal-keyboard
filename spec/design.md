# 界面对稿

入口：Spec 顶部“界面对稿”，或 `#design/typing`。产品世界仍是默认首页；这是同一份规格的界面层。

## 参考什么

2026-10-20 用户提供的七张 Typeless 截图：完整首页、历史、词典、账户，及拼音空闲、候选、语音键区。参考深色层级、错列键位、横竖键隙、候选行复用、分组列表和悬浮底栏。没有复用其标识、促销素材、账号地址或聊天原文。

全高参考图为 578 × 1280 图像像素，可观察比例，无法据此知道设备的 dp、物理尺寸或 Android 字体缩放。因此本稿使用明确标注的逻辑画布：393 × 872 CSS px，另提供 360 × 800、412 × 915。100% 表示 CSS 不缩放，适应窗口会显示实际缩放比；不冒充物理厘米。真机仍需复核系统 insets、字体倍率、触摸手感和可用面积。

## 页面与操作

| 页面     | 可直接试的操作                                                              |
| -------- | --------------------------------------------------------------------------- |
| 日常键盘 | 错列键区、拼音候选、英文/符号、退格、换行，语音与军师入口                   |
| 个性语音 | 待录音 → 录音中 → 个人整理，结果可编辑、填入草稿、查看原文                  |
| 原地军师 | 缩矮读屏 → 自动展开三种建议，每种“更多”、返回、填入和撤销、补前文、失败恢复 |
| 首页     | 统计、最近热词、试用键盘                                                    |
| 历史     | 本机记录、云同步开关、原始转写与整理对照                                    |
| 个人记忆 | 自动/手动热词筛选与搜索，添加、修订、删除、撤销；文风与人物入口             |
| 人物关系 | 图与列表，人物事实、计划、来源、修订和撤销                                  |
| 设置     | 独立 ASR/文本配置入口、学习开关、记忆、同步类别和数据去留                   |

键盘没有常驻三个模式页签，模式按需接管键区。App 底栏用于管理页面，不占用聊天键盘空间。手机里的宿主聊天是演示容器；真实产品仍通过系统输入法与宿主交互。

## 基础尺寸

- 正常键区 326 px；读屏条 92 px。宿主会随高度变化露出更多演示聊天。
- 候选/动作行 48 px；功能按钮命中区 44 × 44 px，图标 22 px。
- 水平键隙 6 px、垂直 8 px；十列均分可用宽度，第二行错列。
- App 内容侧距 16 px、卡片圆角 20 px、悬浮底栏高 62 px。
- 界面支持“间距标尺”；不额外把尺寸标注塞进日常产品 UI。

## 原型与实现的边界

这是 HTML 设计稿：固定的演示人物、语音、识别过程、回复、统计和记忆，页面内交互状态刷新后恢复。拼音只演示少量候选，不是中文引擎。计时模拟不启用录音、不截屏、不请求模型，也不连接设备或上传数据。任何“已填入”只改变本页草稿，没有发送功能。模型页不接收真实密钥。

草稿按演示联系人隔离，切换联系人会取消当前模拟任务；迟到结果不会进入新聊天。更多只展示所选风格的另一组固定候选，返回保留原始三条。数据修订可撤销，不用假负反馈强化记忆。示例中个人文风、人物偏好和热词分开。

本次确定布局与可观察行为。真实 ASR 延迟、中文选词、系统读屏权限、键位触感、模型回复质量和纠错学习仍待实际实现与真机验收。
