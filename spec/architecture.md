# App / Cloud / Spec 架构

目录保持 app/、cloud/、spec/；产品边界固定，方案状态单列。

| 域 | 组成 | 责任 |
| --- | --- | --- |
| 用户手机 | 麦克风、聊天与输入框 | 提供声音 / 截图，承载本人编辑与发送 |
| 输入法 App | 历史、热词、文风、人物 | 本机主本、交互与相关资料选择 |
| Cloud | 代理、账户与权益 | 模型凭据 / 提示词 / 路由，登录与结算 |
| 供应商 | 语音模型、语言与视觉模型 | 接收必要材料，返回结果及用量 |
| 运营后台 | 配置与监控 | 脱敏账户、用量、故障与套餐管理 |

语音和军师沿同一条 App → Cloud → 供应商边界往返，区别是材料与任务。提示词由代理组装，与本次数据一起发向模型；改写、军师和记忆提取不是三个独立域。免费额度读取 cloud/config/plans.json，现有提示词读取 cloud/prompts/。

## 数据和部署

本机保存转写、军师两类历史及个人记忆主本。军师使用截图、相关人物关系、文风与近期已确认发言，不附独立热词表。建议 App 选历史增量，Cloud 按模型预算分片并调用 LLM，LLM 提结构化建议，App 核验修订后落库；处理指针留在本机，旧记录更新也重新入队。[具体方案](memory-and-sync.md)尚未迁移到运行时。付费云备份与推理临时处理分开授权、计量和保留。

所有商业模型走 Cloud，APK 不带供应商密钥。首版按要求内置 https://106.14.73.99/keyboard-api，正常校验证书；后续可迁产品 HTTPS 域名，域名指向服务器或负载均衡。不能通过关闭 TLS 校验绕过地址问题。

一个 API 容器、后台 worker 与独立持久化 PostgreSQL 足够首期。密钥不进镜像，数据留持久卷，服务仅通过 TLS 反向代理暴露。后台单独鉴权，默认不展示私人聊天；无需给每个用户重启一个 harness 容器。

## 权益和模型任务

成功结果结算，失败 / 取消释放预留；同一任务键与欢迎赠送用数据库唯一约束防止重复。用户单位为转写字符 / 军师次数，供应商单位为 token / 音频秒与成本，分开记录。套餐发布后不可原地修改，调整保留快照和审计。

已接入的 ASR 是 Qwen Message 原生实时 WebSocket；个人改写可关闭。军师直接多模态已选择，具体模型与接口字段待验证，运行时尚未迁移。记忆分析推荐受限增量任务，模型只提建议，本机核对来源与修订，不能让模型自由写设备目录。

[当前实现](implementation.md)独立记录已发布 0.4 与服务 readiness，本轮没有重新发布 APK 或迁移 Cloud。
