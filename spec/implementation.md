# 原生实现 · 0.2.0-alpha.1

键盘和管理页属于一个 APK，共用本地资料。此次按 Typeless 的列表层级和豆包的键帽 / 工具格重做原生界面，同时拆开代码域。没有预装模型账号或固定“智能回复”。

| 能力 | 当前实现 |
| --- | --- |
| 键区 | 284dp，单行候选 / 动作；分隔键帽、中英切换、标点 / 符号、长按退格、空格滑动光标 |
| 拼音 | AOSP / libgooglepinyin 离线整句与部分选词；新增 32,136 条简拼索引，包含 `nh`、`lll` 等；个人快捷码及选择频率参与排序 |
| 语音 | 系统 SpeechRecognizer，本地优先；在线服务需主动开启。转写可编辑，文字模型配置后可整理；语音入口、错误和取消均为真实状态 |
| 军师 | 76dp 捕获条 → 布局稳定 → 显式截屏 → ML Kit 本地中文 OCR → 确认人物 → 284dp 结果区 |
| 前文 | 本人滚动后补当前屏，最多六屏 / 16K 字；重叠行合并。没有自动翻页或可靠说话人识别 |
| 回复 | 一次三种表达、同风格更多、最多八组返回缓存；取消或更换编辑器丢弃迟到结果，已有草稿优先 |
| 记忆 | 热词 / 文风 / 历史 / 待学习分段检索；资料修订、删除撤销、保留期限和备份；人物图及分人物的事实 / 事件 / 偏好 / 推断 |
| 模型 | 可选 HTTPS OpenAI / Anthropic 适配器，Keystore 保存密钥、稳定会话标识、限时与取消；尚未配置真实模型 |

`lll` 不被全局写死为“六六六”：简拼先召回多个词，词频与本人的选择再排序；也可添加自己的快捷码。拼音音节解码、简拼词库、个人资料和候选呈现各自独立。英文目前是基础直接输入，没有实现英语自动纠错、多语言预测或完整双拼。

## 代码归属

源码根目录为 `android/app/src/main/java/app/doudou/ime/`。

| 目录 | 职责 |
| --- | --- |
| `app` | Android 生命周期、页面导航、当前 InputConnection 和编辑器代次 |
| `design` | 颜色、字体、间距、行 / 卡片 / 图标 |
| `input` | 键区、候选和按需工具；`engine` 是离线解码与简拼；`learning` 对应上屏范围与修改差异 |
| `voice` | 录音 / 转写状态、系统 ASR 和文字整理流程 |
| `advisor` | 主动读屏任务、人物确认、意图、建议与返回历史 |
| `capture` | 系统截屏与本地 OCR，不读取聊天树、不发送消息 |
| `memory`、`people` | 持久化、修订 / 撤销、词库文风与人物资料 |
| `model`、`security`、`settings` | 远程文字协议、凭据存储、权限和服务配置 |

各面板通过 `EditorHost` 使用当前编辑器；不持有 InputConnection，不拥有发送消息的能力。原先集中在两个巨型页面 / Service 的业务已迁出，旧类和旧组件入口已删除，没有并存的兼容分支。数据库文件、资料结构与 Keystore 标识不变；升级后需在系统重新选择新输入法组件，并重新开启主动截屏。

简拼索引由 `android/tools/build-abbreviations.py` 从同一份校验固定的 AOSP 源词表生成；现代词条在 `expressions.tsv`，摘要和哈希在 `initials-info.json`。算法里没有逐个词特判。

语音和军师上屏后的修改只在范围可对应时进入待学习。输入框清空可能是发送，不是删除证据。自动分类 / 人物记忆抽取、付费 ASR、豆豆同步仍待后续模型联调。

截图不写文件，OCR 完成释放图片。普通打字不读屏；模型只在主动整理 / 生成时接收必要文字。密码框和禁止个性学习输入框关闭语音、军师与学习。虚拟机练习区验收不代表真实聊天 App、其他 ROM 或 ASR 质量。
