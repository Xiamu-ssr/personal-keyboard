# 当前实现 · 0.4.0-alpha.1

本轮只调整 Spec 的域抽象、研究依据与推荐方案，**没有重新发布 APK 或迁移线上 Cloud**。以下是已发布 0.4 的现状，不代表已经认可其产品策略：当前只保存最终转写；修改反馈是未关联语音 recordId 的短文本记录（整段不超过 64 字，观察延迟约 1.2 秒）。尚未分开保存原 ASR、上屏版本、最后改稿。军师仍为本地 OCR / 可选图片；学习结果仍需本人确认。代码中的五小时检查是先前把讨论建议固化的现状，不是已确认需求。新方案见[推荐方案](design-options.md)。

新明确的两类关联历史、军师仅取近期最终发言 / 不附独立热词表，以及按历史修订处理增量，均属于下一版目标；当前最近上下文仍从现有文字记录选取，不能称为已核验的最终发送内容。本轮不单独改提示词来假装完成 App / Cloud 数据协议迁移。

一个原生 APK：键盘、语音、军师、记忆、人物和设置共享本机资料。供应商设置已迁出 App，用户只登录豆豆账户。界面延续 Typeless 的深灰层级和豆包的键帽间距。

| 能力 | 实现 |
| --- | --- |
| 输入 | AOSP / libgooglepinyin 离线整句，32,136条简拼索引，个人快捷码和选择频率 |
| 语音 | AudioRecord → Cloud WebSocket → Qwen Message；实时中间字、热词、近期文字、基础规整；可选后接个人改写 |
| 军师 | 76dp 缩矮 → 稳定布局 → 主动截屏 → 本地 OCR；可选携带当次图片给一次图文模型；结果后恢复高度 |
| 回复 | 三种表达各一条、同风格更多、返回缓存；保留已有草稿，不代发 |
| 本机资料 | 热词、文风、人物、事件、文字历史、来源与候选；删除撤销、保留期限、导入导出 |
| 学习 | 每约五小时检查新增事件，按预算组批；结构化候选在本机确认，不覆盖手动修订 |
| 账户 | 手机验证码、权益余额、登出与注销；本地输入不要求登录 |
| 同步 | 付费可开；设备加密、UUID / 向量时钟、并发差异保留、删除与恢复 |
| Cloud | PostgreSQL账本、幂等任务、ASR代理、异步文字任务、私有同步存储、独立后台 |

`app/` 按 `input / voice / advisor / capture / memory / people / account / cloud / sync / security` 划域；`cloud/` 按 `identity / billing / models / jobs / sync / operator / admin / db` 划域。没有并存的系统 ASR 或 BYOK 协议分支。

SQLite 从旧预览版迁移，保留原文字与人物关系，新增全局标识、修订时钟和增量处理位置。已发布 0.4 的原音频和截图不进入历史；军师文字记录保留 OCR、意图、建议和来源状态。这个截图行为与本轮明确要求不同：下一版需保存军师截图到本机历史。建议不等于对方事实或已发送消息。

当前服务端短信与模型凭据未配置，购买入口关闭；真实手机号、真实麦克风 ASR 准确率和真实聊天 App 尚未完成供应商联调。模拟器练习区、协议 fixture、真实供应商测试必须分别报告。
