# 原生实现 · 0.1.0-alpha.1

一个 APK、一个本地资料库：键盘、管理页、主动截屏服务共享数据。没有预装模型账号，也没有固定的“智能回复”。

| 层 | 当前实现 |
| --- | --- |
| 键区 | InputMethodService / InputConnection，280dp；单行候选与动作；豆包参考的分隔键帽与按需工具宫格 |
| 拼音 | Apache-2.0 的 AOSP / libgooglepinyin，离线词库；整句、部分选词、个性热词与排序；非 Rime / 双拼 |
| 语音 | Android SpeechRecognizer，本地优先，系统在线识别主动开启；独立转写与可选文字整理 |
| 军师 | 76dp 捕获条 → 等布局稳定 → 显式截屏 → 本地 ML Kit 中文 OCR → 确认人物 → 展开 300dp 面板 |
| 前文 | 本人滚动，再主动补当前屏；最多六屏 / 16K 字，重叠行合并。没有自动翻页或气泡说话人识别 |
| 结果 | 三条回复；同风格更多、最多八层返回缓存；取消或换编辑器丢弃迟到结果，新草稿优先 |
| 资料 | SQLite：热词、文风、人物、记忆、历史、反馈与候选排序；修订版本、软删除、撤销、备份与保留期限 |
| 模型 | 可选 HTTPS OpenAI / Anthropic 适配器，密钥经 Keystore 加密；稳定会话标识；限时和取消。尚未配置真实模型 |

语音和军师上屏后的修改只在文字范围可对应时进入待学习。清空输入框可能是发送，不作为“删掉整段”的学习证据。当前由本人确认热词 / 文风和人物资料；自动模型分类、关系抽取和豆豆同步属于后续联调，不能从 UI 或数据库存在推断已经接通。

截图不写文件，OCR 完成即释放图片。系统截屏能力不包含后台读取聊天树、自动手势或发送消息。模型只在本人整理 / 生成时接收本次必要文本；密码框关闭这些能力。

本版面向自用，中文输入细节、各聊天 App 和 ROM、ASR 准确率及模型建议质量仍需持续实用验证。可复核结果集中在验收文档，避免把编译或网页截图当作真机成功。
