# 产品与业务

## 用户得到什么

平时就是好用的中文键盘。说话时，识别并整理成自己的口吻；不知道怎么回时，在聊天里点一下军师，结合当前聊天、自己的意图及这个人的记忆，给出可编辑的回复。

手机屏幕面积是第一约束。常驻只有候选/动作行：候选词占主体，麦克风和军师以紧凑按钮出现。功能进入后接管键区，完成即可返回，不增加常驻三级导航。

## 第一版用户

先服务自用安卓设备，验证朋友、家人、同事/客户三类聊天。恋爱是场景之一；不预设女生会更需要，也不把热闹的话术市场当成产品核心。

## 三条业务链

1. 输入：拼音/英文 → 候选/热词 → 上屏 → 用户修改 → 只在证据完整时学习。
2. 语音：按麦克风 → ASR → 按个人偏好润色 → 预览/上屏 → 修改反馈。
3. 军师：主动触发 → 缩矮键盘 → 截当前聊天 → 必要时补前文 → 三种风格各一条 → 填入并编辑。

三种表达路线必须保持用户的同一立场。不因“更温柔”自动答应约会、付款或承诺具体日期。用户可先用短草稿或语音说明“想拒绝，但愿意下周再约”。

## 数据给谁服务

- 热词与文风：辅助语音识别、整理；语音与日常输入的可信改词、改句反过来更新它们。
- 人物与事件：已知事实、共同经历、沟通偏好，供语音和军师共同使用；每个联系人隔离。
- 记忆来源：已读聊天、用户主动补充，或身份明确的语音 / 输入候选。草稿不等于已发送，计划不等于已经发生，本人陈述不冒充对方表态。本人明确补充的个人事件可形成候选，第三人身份不明时不归人。
- 设置：输入法 App 的统一管理入口，包含模型、词库、文风、人物关系图和授权；点人物看来源、修订或删除。不是另一个 App。
- 豆豆同步：另一个产品的可选连接。按类别和人物授权，默认不上传原始截图、完整聊天或所有击键。同步携带来源、版本和删除标记，不能回灌覆盖用户的新修订。

“人物与事件”是共享记忆，不是军师专属，也不是新增的任务或定时提醒系统。只有军师主动读屏时才读取对方可见消息；日常打字和语音不因此自动截屏。

## 先验证，再收费

自用期先使用现有 CPA 的 Gemini 额度做回复实验，语音和 OCR 走独立能力。未来对外服务用可采购的官方 API 建成本基线，不能按个人优惠订阅的剩余额度承诺用户无限使用。

可独立出售输入法会员；豆豆会员不是使用键盘的前提。收费功能可以包括个性化语音、军师次数、人物记忆同步。具体价格暂不假定，先观察一周真实使用、改写量与重复使用情况。

核心验证：不切应用能否得到可用回复；加记忆是否比同模型无记忆更贴近自己；普通中文输入是否仍然顺手。回复采纳不等于已发送。
