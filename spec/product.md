# 产品与权益

豆豆输入法是一个 Android App：键盘、语音、军师和资料设置共享本机数据。普通打字离线可用，商业模型通过产品 Cloud 提供；豆豆 Agent 是独立产品。

## 已确认的行为

- 打字：成熟离线拼音与候选，普通输入不自动截屏。
- 语音：录音经 Cloud 代理 ASR，返回实时文字；个人口吻整理可开关。成功最终转写进入本机历史，填入后可继续修改，不代发。
- 军师：键盘缩矮、截当前屏；连同相关人物关系、本人文风及近期已确认发言交多模态模型，不附独立热词表。有结果后展开，三种表达各一条，可填入、更多或返回。

同一套域与实体用于两张业务图；切换语音 / 军师只改变传输材料。App 的组成是历史、个人热词、个人文风、人物；Cloud 的组成是代理、账户与权益。处理动作和提示词在数据卡片中表达，不变成额外业务节点。

## 已选方案与待定项

历史分转写与军师，保留原转写 / 截图、所选回复及可靠取得的最终发送内容。已选明确纠词自动加入且可撤销、文风变化和人物冲突先确认。不存逐次编辑快照、按历史修订增量整理是推荐；具体视觉模型、触发条件、预算和存储期限未定。详见[方案与取舍](design-options.md)。

## 账户与权益

本地键盘、资料与历史不以登录为前提。国内 Cloud 能力使用手机号验证码登录；短信资质和真实联调仍待完成。Google 登录与 Google Play 分发 / 支付是不同事情，海外身份留后续。

每个新账户一次性赠送 10,000 个转写字符与 20 次军师。字符按 ASR 成功最终文字计，中间结果与个人改写不重复扣。成功生成一组军师扣 1 次，“更多”成功再扣 1 次；失败 / 取消释放预留，原任务重试不重复结算。成功转写后个人改写失败，保留并结算已成功转写。

免费资料仅存本机；付费套餐可以提供额外用量和产品云备份。价格、额度和期限由后台版本化配置，具体付费方案尚未决定。权益不足不清空本地数据，也不影响普通输入。
