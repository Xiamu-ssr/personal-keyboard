# 产品与权益

豆豆输入法面向公开使用和收费，键盘、语音、军师、资料设置属于同一个 App。普通打字离线可用，联网能力通过产品 Cloud 提供。豆豆 Agent 是独立产品，不是登录或付费前提。

## 用户的三条路径

- 打字：成熟离线拼音与候选，个人选择影响排序；不因普通输入自动读屏。
- 语音：录音与少量热词 / 前文 → Cloud 代理 Qwen Message → 实时文字；个人口吻整理可开关，开启时追加文字模型。上屏后允许编辑，不自动发送。
- 军师：点军师后缩矮 → 布局稳定 → 本地截屏 / OCR（可选图文理解）→ 确认人物和意图 → Cloud 返回三种风格各一条 → 展开选择并填入。更多是新的生成任务，返回本次缓存不再请求。

语音与军师工作方式不同，在 Spec 中使用两张独立业务图；域的固定颜色在两张图和基础域卡片中一致。提示词在 Cloud 组装，并直接连向对应供应商模型。

## 账户与权益

本地键盘、资料与历史不以登录为前提。开始使用 Cloud 能力时登录：国内优先手机号验证码，海外接 Google 登录；Google Play 是分发和支付渠道，与 Google 登录不同。

每个新账号一次性获赠 10,000 个转写字符与 20 次军师，不按月重置。字符以 ASR 成功最终文字计，中间字不重复累计；个人改写不再次扣转写字符。一次军师成功生成一组结果扣 1 次，更多成功再扣 1 次；失败 / 取消释放未完成预留，同一任务重试不重复扣。已成功转写后改写失败，仍保留并结算这次成功转写。

免费账户的文字历史与记忆仅存本机，不提供云同步。付费套餐可含额外用量和产品云同步；具体价格、额度、有效期尚未决定，由后台版本化配置，不写死在 App 流程里。权益不足时仍可普通输入和查看本地资料，不清空用户数据。

## 数据与学习

本机保存转写、可选改写、军师 OCR / 意图 / 建议和可确认的修改。热词、文风、人物事实 / 事件 / 偏好分别保留来源和修订；截图处理后释放。建议不是对方事实，选中不证明已发送，输入框清空不等于删除。

约每 5 小时检查新增历史，按 token 预算组批，经 Cloud 学习提示词和文字模型提取候选，本机校验版本再合并；没有新增不调用。学习成本关联服务预算，不另设一个向用户扣费的“学习次数”。

产品提供付费云同步，不让用户配置 WebDAV、存储平台、Bucket 或密钥。App 加密增量包，Cloud 按账号隔离保存；换机恢复由产品流程完成。同步与模型分析是不同用途，上传哪些资料必须说明；模型处理仍需本次必要明文。

## 当前边界

App 与 Cloud 已有实际代码和数据库实现。当前企业短信与服务端模型凭据未配置，在线能力明确显示待配置；付费套餐与支付尚未开放。国内先做手机号登录，海外身份留后续。
