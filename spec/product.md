# 产品与权益

豆豆输入法是一个 Android App：键盘、语音、军师与资料设置。普通打字离线可用，商业模型经 Cloud 提供；豆豆 Agent 是独立产品。

## 已确认的行为

- 打字：离线拼音与候选。本机热词缓存可供个人词库和候选排序使用，不逐键调用模型。
- 语音：音频经 Cloud 代理 ASR，实时返回文字；个人口吻整理可开关。原转写、实际填入稿与本人最后有效修改稿关联在同条本机历史，不代发。
- 军师：缩矮、截屏、一次多模态；携带相关人物关系、本人文风与同对话近期表达，不附独立热词表。结果展开，三种表达各一条，可填入、更多或返回。
- 学习：直接启用自动学习，不提供“询问 / 自动 / 关闭”三档。明确纠词自动入词且可撤销；文风变化与人物冲突保留确认。

## 数据归属

App 下是历史、记忆缓存；Cloud 下是代理、账户与权益、热词、文风、人物。两张业务图使用同一组域与子节点，任务、提示词和传输内容放在线间卡片中。

文字历史与军师截图保存手机。Cloud 管理三类个人记忆主本，手机同步缓存供离线使用；历史片段只在本次分析时按需上传。个人记忆同步属于账户基础能力，完整历史 / 截图云备份是单独的付费权益。详见[历史与记忆](memory-and-sync.md)。

## 账户与权益

普通离线输入不以登录为前提。国内 Cloud 能力先使用手机号验证码；真实短信资质和联调仍待完成。Google 身份、Play 分发和支付后续分别接入。

每个新账户一次性赠送 10,000 个成功最终转写字符与 20 次军师。中间文字和个人改写不重复计字符；成功生成一组回复扣 1 次，“更多”成功再扣 1 次。失败 / 取消释放预留，原请求重试不重复结算。个人改写失败不抹去已成功转写。

价格、赠送与套餐特性由后台版本化配置，付费价格仍未定。权益不足不清空本机历史或已有记忆缓存，不影响普通输入。账户注销与主动删除必须传播到主本与缓存。
