# 历史与个人记忆

**历史分转写、军师两种，均在手机；热词、文风、人物是从历史提炼的个人记忆。** 已选直接多模态、明确纠词自动且可撤销，文风变化与人物冲突先确认。下面的最小记录与更新机制是推荐设计，尚未迁移到 0.4 APK。

## 一次输入，一条历史

| 类型 | 来源 | 实际填入稿 | 结果 |
| --- | --- | --- | --- |
| 转写 | ASR 最终原文 | 本次真正填入的文字；可能经过可选整理 | 最后可靠观察的本人版本，以及发送证据状态 |
| 军师 | 本次截图、看图文字依据 | 本人选中的回复 | 最后可靠观察的本人版本，以及发送证据状态 |

截图、原转写、军师选中的回复及实际发送内容属于已明确的历史需求；**实际发送内容只有可靠取得时才能填，缺失不补猜**。没有选回复也保留本次军师截图。未选建议仅供本次返回查看，不必全量作为长期记忆材料；具体保留策略待定。

推荐不存逐次改稿快照。编辑期间只覆盖一份最新有效文字，历史保留来源、实际填入稿和这份结果；相同文字可以复用。实际填入稿是识别“用户改了什么”的基线：若 LLM 先润色，再比较 ASR 原文与最终稿，就会把模型润色误学成用户纠错。军师的选中回复就是这条基线，不另复制一份“最终答案”。

观察仅限本次可归属的填入范围，用编辑器会话、选区与锚点核对。文字取不到或归属不明就停止该样本；输入框清空时不把空串覆盖为最终结果。可以保留一个最小纠词证据引用，不另存编辑时间线。

## 发送与近期上下文

安卓标准 IME 接口不提供跨所有聊天 App 的最终消息回执。读取文字可能返回空或截断；performEditorAction 只是请求编辑器动作，其成功值不是聊天消息送达证明。清空、失焦、结束输入也不能据此判成发送。[Android 官方接口](https://developer.android.com/reference/android/view/inputmethod/InputConnection#performEditorAction(int))。

结果文字与证据状态放在同一条历史：未确认稿不叫“实际发送”。若只能观察到用户按发送动作，仍不等于取得最终消息。首期不为补齐字段而常驻截屏或要求每条确认；没有可靠证据就留缺失。军师当前截图中可见的本人消息可直接作为当次对话材料，历史关联有歧义时不自动回填。

**军师材料已明确：本次截图 + 相关人物关系 + 本人文风 + 同一对话的近期最终发送内容。** 不附独立热词表，不拿原 ASR 或未确认草稿冒充最近已发送消息。对象未知时不拼入其他人物历史；当前截图本身也提供近期上下文。ASR 的识别热词仍单独使用。

## 谁来更新

| 责任方 | 推荐动作 | 持有结果 |
| --- | --- | --- |
| App | 记录变化；在输入结束、空闲且联网时，选未处理历史及相关旧记忆，组成有大小上限的一批 | 本机历史、待处理位置 |
| Cloud | 校验身份与预算，按模型上下文预算分片，附学习提示词，调用供应商 LLM | 任务状态；不是个人记忆主本 |
| 供应商 LLM | 阅读本批来源，提出结构化的热词、文风、人物更新，逐项引用来源 | 建议，不直接写数据库 |
| App | 核对来源修订与手动修改，应用或暂存候选，成功落库后提交处理位置 | 本机个人记忆 |

这叫更新记忆数据，**不训练模型、不改模型权重，也不删掉原历史**。空闲触发负责避开正在修改的输入，Cloud 按实际模型 token 预算分片；每片沿历史记录 / 语义段落切开并带来源位置，不硬截字符串。长单条可以分片，失败只重试未完成部分；App 只确认已验证落库的来源。

## 指针跟踪“变化”，不只跟踪新增

推荐每条历史有稳定 ID、修订号和递增变化序号。比如记录 41 已经整理过，后来补到了实际发送文本，仍要获得新变化序号再次进入增量。只记“上次读到第 100 条”会漏掉这次补写。

上传的是本批来源的固定修订及相关旧记忆，不是整个时段的全库。返回时来源又变了就不应用过期建议，重排最新修订；删除保留无正文的删除标记，用于撤回关联证据。分片位置、候选应用与处理位置可恢复且幂等，重试不重复累加。这个轻量变化索引不需要保存每一版全文。

## 三类记忆分别判断

- **热词**：明确的用户纠词优先；不要求那句话已发送，但必须确实是本人改词。单纯高频、删句或改意图只能作为候选，不能自动全局替换。
- **文风**：取本人可靠最终表达及主动修改；模型原稿不单凭被选中就变成已学偏好，反复使用模型稿也不能当成独立证据无限强化。新风格先确认。
- **人物**：有说话人归属的截图、本人明确陈述都可作为来源。区分“对方说”“本人说”，草稿里的计划不变成已经发生的事实；人物冲突先确认。

建议军师首次看图时一并返回有说话人和截图位置的文字依据，在同条历史留存。日后整理通常取这份带来源文字；读图有疑问再核原图，避免每轮重读全部截图。这是待验证的结果协议，不是独立 OCR 前置。

## 本机、分析与备份

免费仅本机保存；付费可开启产品云备份，不暴露存储供应商设置。推理临时上传与持久云备份分开授权；免费本地保存也不表示使用云模型时材料不出设备。图片压缩去重、占用与清理入口是建议，原始录音和截图的保留期限 / 备份范围仍待定。

当前 0.4 的固定五小时任务、独立反馈记录和 OCR 路径尚未按上面方案迁移；账号恢复式加密备份也不是端到端加密。详见[当前实现](implementation.md)。
