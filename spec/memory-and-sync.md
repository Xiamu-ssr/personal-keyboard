# 历史与个人记忆

**历史在手机，个人记忆主本在 Cloud，手机同步缓存。** 自动学习直接启用；明确纠词可自动加入且可撤销，文风变化与人物冲突先确认。下面是目标协议，尚未迁移到 0.4。

## 一次输入，一条历史

| 类型 | 来源 | 实际填入稿 | 本人结果 |
| --- | --- | --- | --- |
| 转写 | ASR 最终原文 | 实际填入的文字，可能经过可选整理 | 最后一份可归属的有效修改稿 |
| 军师 | 截图、识别出的聊天内容 | 本人选中的回复 | 最后一份可归属的有效修改稿 |

编辑只更新这条记录，不存逐次按键快照。实际填入稿是比较基线，防止把 ASR 与 LLM 润色的差异误当用户纠词；输入框清空不覆盖掉最后有效文字。改稿观察限于本次输入的范围、会话和锚点。

原文用于纠错分析，近期表达优先本人修改稿；军师只取同一对象的相关历史。本人表达与聊天事实是不同证据，不能把未采用的建议或本人草稿记成对方说过的话。若截图提供可靠的实际已发送内容，可关联更新原记录；不以发送回执作为学习的前提。

“识别出的聊天内容”是同一次多模态返回的说话人、可见消息与来源位置。截图和这份文字一起留本机，之后学习通常用文字，避免反复读全量图片；无需独立 OCR 阶段。

## 谁来更新

1. **App**：输入法服务记录新增 / 修改历史及待处理队列，不要求打开 App 首页。联网时提交有界增量，后台调度负责延迟与失败重试，不要求常驻。
2. **Cloud**：接收任务后独立运行，读取相关旧记忆，合批、按模型 token 预算分片并附提示词。清楚的纠词优先，文风和人物证据合批；具体预算和合批参数仍未定。
3. **LLM**：返回新增 / 修改 / 删除建议，带对象 ID、预期版本和来源历史 ID / 修订；不执行 SQL，不直接改文件。
4. **Cloud**：核验归属、来源、字段、版本和人工修改，事务更新记忆；文风变化和人物冲突进入待确认记录。完成的任务不依赖 App 在线。
5. **App**：下次使用键盘时，从同步游标拉取完整变更记录与删除标记，事务写入缓存。网络断开仍可使用已有缓存，离线手动修改排队提交。

## 三类记录的粒度

| 数据 | 稳定标识与范围 | 修改方式 |
| --- | --- | --- |
| 热词 | wordId，文字、适用范围、来源与版本 | 更新一条词记录，不做无条件全局替换 |
| 文风 | styleId 与 scope；先有通用档案，证据明确再区分工作 / 朋友等场景 | 更新该小档案的偏好、例句、来源；展示名称可改，不作身份键 |
| 人物 | personId；每条事实另有 factId、属性、值、时间和来源 | 任职公司变了只改对应事实，不整个人物覆盖；关系可以引用另一个 personId |

因此同步采用 **整库增量、单条完整**：只下发改变的词、文风档案、人物身份或人物事实，但每一条都是完整记录；删除单独发标记。本机按 ID 和版本写入，不自行解释模型给出的 JSON 路径。

例如 LLM 可提出：`upsert_fact(personId=P1, factId=F2, attribute=employer, value=某公司, expectedVersion=3, source=H41@2)`。Cloud 检查 F2 是否仍为版本 3、来源是否仍有效，以及是否与手动资料冲突，再决定提交或等待确认。模型不能靠同名猜定是同一个人。

## 增量、冲突与重试

历史有稳定 ID、修订和递增变化序号；旧历史修改也产生新变化。Cloud 保留已接收来源的修订索引与证据引用，学习任务处理固定修订，处理位置只在成功提交后推进。重复提交同一来源修订不重复强化；后续修改或删除触发受影响记忆的重新判断。

已知过期的来源和目标版本不能覆盖新资料；手机尚未上传的修改到达后重新核对相关证据。人工修改有优先级，冲突可确认；不凭一个模型置信分数强行合并人物。超长内容按记录 / 语义段分片，失败只重试未完成部分，不重读全库。

固定数据类型采用受限任务与结构化校验，不需要通用 harness 挂载用户目录。每用户三类目录可以作为导出格式，不能替代版本、身份和合并规则。

## 保存与权益

手机保存文字历史、截图与记忆缓存，Cloud 持久保存热词、文风、人物及其来源引用。学习仅临时上传本批必要片段，任务缓存按保留策略清理；来源引用不要求在 Cloud 永久保留原截图或整段聊天。

个人记忆同步是基础账户能力。完整历史 / 截图云备份单独按付费权益开放，不暴露存储供应商配置。模型分析、个人记忆主本和历史备份的用途与保留分别说明；不承诺供应商零留存。截图保留期限、备份容量与原录音保留策略仍未定。

当前 0.4 仍是本机记忆主本、固定五小时学习和 OCR / 可选图片路径。本轮只改 Spec，运行时迁移见[当前实现](implementation.md)。
