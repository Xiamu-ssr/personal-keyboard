# 历史与记忆更新

本地是主本。Cloud 负责短任务推理与付费同步，不把用户的完整日常历史搬进一个长期 Agent Session。此处为目标契约；自动提取和产品云同步尚未实现。

## 保留哪些材料

| 来源 | 本地文字历史 |
| --- | --- |
| 语音 | 原转写、可选改写、可信最终编辑、应用 / 人物范围、模型与设置版本 |
| 军师 | OCR 文字与说话人不确定性、意图、三条建议、选择与可信修改、引用记忆版本 |
| 已学记忆 | 热词、个人文风、分人物事实 / 事件 / 偏好；来源、修订和删除标记 |

截图不归档，音频仅临时缓冲，不记录所有击键。建议不是对方事实，选中不等于发送；清空输入框不能当删除证据。人物不确定不归人，计划不冒充已发生。历史可设保存期限；删除后未处理证据作废，既有派生记忆标明来源已删，可由用户保留或删除。

ASR 仅带当前范围内少量近期文字和热词。Message 目前每种角色最多 5 条、每轮合计 400 字符，不把整个历史塞进去。文风用于可选文字改写，不假定识别前文会自动训练出个人口吻。

## 两条业务共用的增量流程

    App 记录新增文字 / 可信修改
      → App 按人物、来源和 token 预算分批
      → Cloud：学习提示词＋增量＋相关旧记忆
      → 供应商文字模型：结构化候选
      → Cloud 校验结构与来源
      → App 校验 revision，事务合并并推进游标

约每 5 小时检查新增内容，受 Android 后台调度影响；也可手动整理。无新增不调用。初始每批输入预算 8K token，预留输出；长条目按原来源位置切片。积压限制本轮批数，之后续跑，不把 5 小时所有文本一次丢给模型。

任务记录 `jobId / deviceId / fromCursor / toCursor / baseRevision / modelVersion / promptVersion`；输出 `proposals[{category,scope,subject,content,sourceIds,baseRevision,confidence}]`。只许引用本批允许的真实证据 ID；同一证据不因切片 / 重试多次强化。一条改写不直接形成永久人格，未知最终文字不参与纠错学习。

Cloud 不写设备目录。设备合并时用户手改和删除优先，冲突保留为候选或重算；模型不复活删除项。提交成功才推进游标。固定提取 / 合并工作流足够，不为每批启动通用 harness 容器，不需要 shell 或浏览器。

## 付费产品云同步

免费用户的历史与记忆只在本机；免费试用模型仍需将当前任务必要材料发到 Cloud / 供应商，这不等于云存储。付费用户可开启产品云同步，无需配置第三方存储。

App 上传加密增量包与清单，Cloud 验证权益、账号归属、大小和版本，保存到私有对象存储。事件使用设备唯一 ID＋序号，实体使用全局 ID；带修订、墓碑、摘要和幂等标识，不同步活动 SQLite / WAL。换机通过产品登录和恢复流程下载并合并，不能整库覆盖新修订。

云备份加密与云端推理是不同边界：供应商仍能接收本任务必要明文。同步开关不自动授权其他用途。到期不清空本地数据，停止新上传，按明示保留策略提供导出；不会因后台切换套餐删除本机资料。

本轮不注册或购买存储平台。对象存储供应商由运营方配置，用户侧只展示“云同步”。
