# 历史、学习与同步

本机是资料主本。Cloud 做短任务推理和付费备份，不为每个人维持长期 Agent Session，也不把资料交给能任意写目录的 harness。

## 保存与使用

| 资料 | 用途 |
| --- | --- |
| ASR 最终文字、可选改写、可信修改 | 本机历史；少量近期文字辅助下一次识别 |
| 军师 OCR、意图、三条建议、人物与来源状态 | 恢复本次表达上下文；建议不等于事实或已发送 |
| 热词、文风、人物 / 事件 | 分别管理，提供相应任务需要的记忆 |

不保存原音频或截图，不归档所有击键。普通打字不读屏；输入框清空可能是发送，不能当作整段删除。OCR不能可靠确认说话人时，不自动写入某个人的事实。

Qwen Message 的近期上下文限400字符，用于听懂专有词；个人文风由独立的可选文字改写处理。

## 增量更新

开启后，Android后台约每五小时检查新增文字；没有新增不调用，也可手动整理。App每批最多12条、约8K字符，单条按1600字符切片，保留断点，下一批继续，不把超长记录直接截掉。Cloud总请求有16K字符上限与每日预算。

Cloud组装学习提示词，模型只返回 `proposals[{category,scope,subject,content,sourceIds,baseRevision,confidence}]`。服务器校验分类、人物范围和来源白名单；App关联原始修订与片段位置，保存为待确认候选。原记录被修改或删除时不再采纳旧候选，手动资料不被模型直接覆盖。

提交本批候选和处理位置后，再推进断点。重试复用任务标识；同步时交换已处理位置和内容摘要，避免另一台设备重复强化相同来源。人物、事件候选也可来自身份明确的语音，不只限军师。

## 产品云同步

免费资料保留本机，模型处理当前必要材料不等于免费历史托管。付费可开启云同步，用户无需配置存储平台或密钥。

App上传设备加密的资料包，Cloud按账号校验权益、容量和清单版本。资料使用全局UUID及向量时钟：能区分后续修改和两台设备的并发修改；并发删除和手改优先，另一版本保留待确认。删除、撤销和恢复都有修订，不能把云备份整库覆盖本机。

同步密钥在设备Keystore与Cloud主密钥封装下保存，换机恢复要近期短信验证，属于账号恢复的加密备份，不宣称端到端加密。模型分析和备份分别开关；截图永不进备份。

Cloud会为幂等任务恢复保留最长24小时的加密文字缓存；同步包另有付费权益校验。付费套餐和到期云保存策略仍未开放，当前不能购买。
