# 豆豆输入法 Cloud

产品 API、运营后台与任务 worker 在同一轻量 Node 容器中，账本使用独立 PostgreSQL。单副本部署；启动会释放中断任务，客户端可按原 requestId 重试。供应商凭据留在服务端。

| 域 | 代码 |
| --- | --- |
| 手机号登录、验证码、会话轮换 | `identity/` |
| 欢迎赠送、预留、结算、幂等 | `billing/`、`db/` |
| 实时语音、文字与图文模型 | `models/`、`jobs/` |
| 个人记忆主本、增量队列、结构化校验与版本提交 | `memory/` |
| 私有加密备份、版本比较 | `sync/` |
| 管理员、套餐发布、权益调整、审计 | `operator/`、`admin/` |
| 提示词、套餐初始版本 | `prompts/`、`config/` |

## 运行

在 `deploy/` 把两个 `.env.example` 复制为对应 `.env`，配置数据库密码、随机主密钥、令牌密钥及 scrypt 管理密码哈希，权限设为 600。生成后保留这些密钥，升级不得重建。执行 `docker compose -f cloud/deploy/compose.yaml up -d --build`。只监听宿主 loopback 8088；Nginx 转发 `/keyboard-api/`，包含 WebSocket 和关闭请求体落盘缓冲。

App 入口：`https://106.14.88.147/keyboard-api`；后台：`/keyboard-api/admin/`。使用正常系统证书验证，不信任全部证书，不把供应商密钥放进 APK。换 IP 需要发新 APK；后续采用域名可只更改 DNS。

缺少短信或模型配置时，接口返回明确的 NOT_READY，后台显示待配置。短信服务开通不代表签名可用，需企业资质、签名、模板及仅有 SendSms 权限的服务凭据。验证码五分钟、五次尝试、六十秒重发冷却，并限制号码、IP 与全站日量；默认全站每天最多20条。SendSms 超时不自动重发。

ASR 为 `qwen-audio-3.1-asr-flash-message`，原生 WebSocket；每段90秒、最多2000个非空白码点，受剩余额度限制。改写、记忆更新和军师共用 `qwen3.8-flash`，直连百炼业务空间的 OpenAI 兼容端点；军师上传图片，其余只用文本，不经 ZenMux 或个人 CPA。该模型非思考输入上限991,808、总上下文1,000,000，记忆更新预留8,192输出 tokens。记忆上传每批最多24条；Cloud 只分批历史，每次携带完整旧记忆。容量检查使用固定版本的官方 Qwen 分词器、聊天模板及256个协议预留 tokens；它是容量预算，不宣称等于账单计数。分词在独立且限额的 worker 中执行；返回的实际输入用量若超出预算，暂停更新并保留待办。容量不足不回退到字符估算。模型返回经过结构、来源和版本校验。

## 权益与数据

每账号一次性10,000字符、20次军师。成功最终结果才结算；更多是新任务，原请求重试不重复扣。套餐发布后不可修改，发放保存快照，运营调整需原因并审计。用户单位与供应商 token / 秒分开。

原音频不归档，截图保存在手机；Cloud 只将本次截图用于图文推理。历史增量加密排队，处理成功后擦除正文、保留去重标识。模型任务输入 / 结果加密保存最多24小时用于恢复；这是处理缓存，不是免费云历史。后台显示脱敏用户、任务状态、usage 和错误码，不提供聊天查看接口。

个人记忆通过基础账户 API 同步完整变更记录、删除标记与版本；手动编辑使用 baseVersion 和 requestId。明确纠词可自动入库，文风与人物资料先确认。完整历史备份按付费权益使用设备加密包和云端清单版本，恢复不覆盖本机已有的同 ID 记录。同步密钥由服务端主密钥封装，换机需近期短信验证，**不宣称端到端加密**。

管理员独立登录，密码 scrypt、会话 Secure/HttpOnly/SameSite、写操作 CSRF 与来源校验。主密钥、数据库及同步卷应一起备份。默认不含第三方密钥、付费套餐定价和支付商户；购买入口明确关闭，不根据客户端“支付成功”发放权益。

## 验证

`npm test` 运行纯逻辑检查。数据库集成测试需专用、可丢弃 PostgreSQL，显式设置 `KEYBOARD_DATABASE_TEST=1`；测试配置保存在忽略的 `.runtime/v05/test-env.json`。测试通过依赖注入使用假短信和模型，生产配置没有绕过验证码的开关。

2026-10-22 已把企业百炼专用密钥部署到轻量服务器，仅允许该服务器 IP 和上述两个模型。真实调用已验证：实时 ASR 返回中间与最终文字、军师读取自有练习截图、文字整理、纠词操作通过领域校验。验证材料不是用户真实聊天，也不代表全面准确率验收。企业短信已开通，但资质、签名、模板与发送凭据仍待完成；手机号登录因此暂不可用。正式支付和计费运营未启用。
