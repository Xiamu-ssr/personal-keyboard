# 豆豆输入法 Cloud

产品 API、运营后台与任务 worker 在同一轻量 Node 容器中，账本使用独立 PostgreSQL。单副本部署；启动会释放中断任务，客户端可按原 requestId 重试。供应商凭据留在服务端。

| 域 | 代码 |
| --- | --- |
| 邀请注册、账号密码、恢复码、会话轮换 | `identity/` |
| 欢迎赠送、预留、结算、幂等 | `billing/`、`db/` |
| 实时语音、文字与图文模型 | `models/`、`jobs/` |
| 个人记忆主本、增量队列、结构化校验与版本提交 | `memory/` |
| 私有加密备份、版本比较 | `sync/` |
| 管理员、套餐发布、权益调整、审计 | `operator/`、`admin/` |
| 提示词、套餐初始版本 | `prompts/`、`config/` |

## 运行

在 `deploy/` 把两个 `.env.example` 复制为对应 `.env`，配置数据库密码、随机主密钥、令牌密钥及 scrypt 管理密码哈希，权限设为 600。生成后保留这些密钥，升级不得重建。执行 `docker compose -f cloud/deploy/compose.yaml up -d --build`。API 仅监听宿主 loopback；Nginx 转发 `/keyboard-api/`，包含 WebSocket 和关闭请求体落盘缓冲。发布时可先用另一个本地端口健康检查，再切换反代。

App 入口：`https://106.14.88.147/keyboard-api`；后台：`/keyboard-api/admin/`。使用正常系统证书验证，不信任全部证书，不把供应商密钥放进 APK。换 IP 需要发新 APK；后续采用域名可只更改 DNS。

注册使用单次邀请码，账号为3—32位字母、数字、下划线或短横线；密码12—128字符，异步 scrypt N32768/r8/p3、独立随机盐，同时最多两次 KDF。限制账号、来源 IP 和全局尝试量。邀请码和恢复码均为256位随机值，完整值只返回一次，数据库不存明文。恢复后轮换恢复码并注销旧会话；登录、换机、恢复都不重发欢迎赠送。管理员可批量生成、撤销邀请码，支持邀请数十至百名试用者。

同时最多8个语音 WebSocket、改写/军师并发2且排队与运行总量16、串行记忆更新1；这是并发上限，不代表支持百人同时说话。密码计算与分词均避开主事件循环。Cloud 上限768MiB、PostgreSQL192MiB，数据卷独立。账户、额度、任务为关系表；个人记忆为绑定账户的 AES-GCM 加密 JSON 存于 PostgreSQL，版本与领域操作在事务中提交，不使用文件 harness。

ASR 为 `qwen-audio-3.1-asr-flash-message`，原生 WebSocket；每段最长90秒，接近2000个非空白码点时结束本段收音并保留完整返回；实际时长受剩余积分限制。改写、记忆更新和军师共用 `qwen3.8-flash`，直连百炼业务空间的 OpenAI 兼容端点；军师上传图片，其余只用文本，不经 ZenMux 或个人 CPA。该模型非思考输入上限991,808、总上下文1,000,000，记忆更新预留8,192输出 tokens。记忆上传每批最多24条；Cloud 只分批历史，每次携带完整旧记忆。容量检查使用固定版本的官方 Qwen 分词器、聊天模板及256个协议预留 tokens；它是容量预算，不宣称等于账单计数。分词在独立且限额的 worker 中执行；返回的实际输入用量若超出预算，暂停更新并保留待办。容量不足不回退到字符估算。模型返回经过结构、来源和版本校验。

## 权益与数据

军师首次/换一批各调用一次多模态模型，返回全部六格；单槽换说法调用一次返回三条，浏览旧答案不调用。思考预算4,096 tokens，严格 JSON Schema 约束完整回复与聊天摘录；不另跑 OCR。视觉容量检查计入 schema，另为图片计4,096 tokens/张，并保守预留16,384 tokens 覆盖输出、思考与协议。参考[结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)和[思考预算](https://help.aliyun.com/zh/model-studio/deep-thinking)。

默认六槽：克制暧昧、Mean、接梗、共情、干练、边界。默认升级只替换未修改的旧槽位；自定义名称和属性保留，迁移只执行一次。供应商错误分别记录余额、免费额度、限流和授权错误；后台保留安全错误码与请求ID，不保存错误正文。

每新账号一次性3,000 Credit；1 Credit=0.001元。语音、润色、军师和翻译统一积分，以阿里云北京公开标准价上浮75%，按成功任务的真实输入/输出Token结算。任务冻结费率、预留并退余，失败/取消不扣、原请求恢复不重复扣。自动记忆学习包含在当前服务成本内，不另扣分。赠送套餐与供应商计价独立版本化；后台改价不影响已有任务。旧字符/次数额度一次性转换并归档；回退旧API必须还原数据库备份。计价不包含赠额、促销和缓存折扣。

Cloud 不归档原音频；独立录音笔原音与军师截图保存在手机。Cloud 只将本次截图用于图文推理。历史增量加密排队，处理成功后擦除正文、保留去重标识。模型任务输入 / 结果加密保存最多24小时用于恢复；这是处理缓存，不是免费云历史。后台显示脱敏用户、任务状态、usage 和错误码，不提供聊天查看接口。

个人记忆通过基础账户 API 同步完整变更记录、删除标记与版本；手动编辑使用 baseVersion 和 requestId。可靠的新热词、文风与人物资料自动生效；实际事实冲突和人工保护项在对应资料旁核对。完整文字与截图备份按付费权益使用设备加密包和云端清单版本，恢复不覆盖本机已有的同 ID 记录；录音原音不进入备份。同步密钥由服务端主密钥封装，换机需近期密码验证，**不宣称端到端加密**。

管理员独立登录，密码 scrypt、会话 Secure/HttpOnly/SameSite、写操作 CSRF 与来源校验。主密钥、数据库及同步卷应一起备份。默认不含第三方密钥、付费套餐定价和支付商户；购买入口明确关闭，不根据客户端“支付成功”发放权益。

## 验证

`npm test` 运行纯逻辑检查。数据库集成测试需专用、可丢弃 PostgreSQL，显式设置 `KEYBOARD_DATABASE_TEST=1`；本轮测试需 `KEYBOARD_TEST_ENV` 指向忽略目录内的本机专用配置；Credit 测试限定数据库 `keyboard_v091_test`。测试通过依赖注入使用假模型；身份、会话和权益使用真实 PostgreSQL，无测试登录后门。

2026-10-22 已把企业百炼专用密钥部署到轻量服务器，仅允许该服务器 IP 和上述两个模型。真实调用已验证：实时 ASR 返回中间与最终文字、军师读取自有练习截图、文字整理、纠词操作通过领域校验。验证材料不是用户真实聊天，也不代表全面准确率验收。0.6 移除短信路径，改为邀请注册和账号密码登录。正式支付和计费运营未启用。
