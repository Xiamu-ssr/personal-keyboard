# 豆豆输入法 Cloud

Cloud 是产品服务边界：记录账号、权益与用量，代理 ASR / 文字模型，管理提示词版本和付费云同步，提供独立运营后台。App 只持产品登录凭证，供应商密钥不下发。

当前目录包含可测试的权益领域逻辑、版本化套餐配置、HTTP 目标契约和容器骨架。账号登录、数据库事务、模型代理、支付验签、私有云同步和运营后台尚未实现；`/healthz` 明确报告 `productionReady=false`，不能把这个骨架作为已上线商业服务。

| 目录 | 归属 |
| --- | --- |
| `config` | 套餐和供应商路由；Spec 读取同一份套餐配置，不复制数字 |
| `domains` | 权益、预留、结算与幂等的领域规则 |
| `contracts` | 面向 App / 运营后台的 API 与账本约定 |
| `prompts` | 改写、军师与记忆抽取提示词；Cloud 组装并发给文字供应商 |
| `deploy` | 容器运行与 HTTPS 入口约定 |

开发验证：`node --test cloud/test/*.test.mjs`。本机启动骨架：`node cloud/server.mjs`；容器：`docker compose -f cloud/deploy/compose.yaml up --build`。仅映射 loopback 8088，不部署到 ECS 或连接真实供应商。

欢迎权益由 `config/plans.json` 发布版本决定：每个账号仅赠送一次 10,000 个转写字符、20 次军师，免费账户只本地存储。“更多”是新军师任务；失败与同任务重试不重复扣。个人改写和例行学习不另建用户扣费项，成本计入所归属任务与套餐的后台预算。付费套餐金额与额度未定，保留草稿，不能购买或授予。

配置变更生成新版本。权益发放时复制套餐快照；后台发布新版本不追扣老用户，不重置已用量。若要迁移存量权益，单独生成可审计调整记录。正式支付只认服务器验证的订单与交易回执，不能信客户端“支付成功”。领域参考目前在内存执行；上线前必须在 PostgreSQL 事务中用账号锁和唯一键实现相同不变量，进程 Map 不是生产账本。

App 的 `API_BASE_URL` 是稳定 HTTPS 域名。域名解析到服务器 / 负载均衡，再由反向代理转到 Cloud 容器。服务器 IP 可变，域名通常不必变；域名本身也要预先配置在 App 中，更换域名仍需预置迁移或发新版。证书必须受系统信任。
